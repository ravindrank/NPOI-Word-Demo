# NPOI-Word-Demo

A quick demo of using NPOI (https://github.com/tonyqus/NPOI) to generate a Word document programmatically using .NET. For now just generates a word file TestWord.docx

# Instructions

## For MVP

- Create a program to Generate a word document on the fly/programmatically
- Upgrade code from .net 8 to .net 9
- Use .NET and C#
- Make it modular and reusable
- Generate Unit test cases to test and validate the functionality

## For 2nd Stage

- Add a simple UI for user to provide options on the type and content of the word document to be generated
- Allow user to provide a filename
- Allow user to provide title and content
- Generate Unit test cases to test and validate the functionality

## For 3rd stage

- Provide an option to generate title and content based on Generative AI
- Generate Unit test cases to test and validate the functionality
